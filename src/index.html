    Plugins y comunidad

    MK todavía no tiene sistema de plugins — todo lo que ves (temas, exportar, etiquetas, etc.) viene integrado en la app, no hay forma de instalar extensiones de terceros por ahora.

    Algunas de las ideas que estaban acá ya se hicieron como funciones propias de MK: corrector ortográfico (nativo, mientras escribís), snippets de texto (⚙ Ajustes), plantillas con variables ({{fecha}}/{{titulo}} en "Nuevo ▾"), nota diaria (paleta de comandos) y diagramas Mermaid (bloque ```mermaid``` en el preview) — ver MANUAL.md para cómo usarlas.

    Lo que queda pendiente:

    Organización y visualización

    • Vista de grafo — mapa visual de qué nota enlaza con cuál, a partir de los wikilinks.
    • Tablero Kanban — armado automáticamente a partir de listas de tareas (- [ ]) agrupadas por columna.

    Exportar e integraciones

    • Exportar a EPUB — para apuntes largos o libros armados en Markdown.
    • Sincronización con git — commit automático de la carpeta al guardar, sin salir de MK.
    • Exportar a tarjetas de memoria (tipo Anki) — a partir de encabezados o callouts.
