# Materiales dentro de una nota

Abre **Ejemplos** como carpeta raíz. Activa Preview o Live Preview para ver estos dos archivos sin salir del Markdown.

## PDF de demostración

El PDF siguiente es una muestra de fotosíntesis, no contenido de PCP. Sirve para comprobar navegación y apertura del visor. Puedes sustituir su ruta por un PDF de tu asignatura dentro de la carpeta abierta.

![[../pdf/apunte-fotosintesis.pdf#page=1|PDF de demostración]]

Usa **Anterior/Siguiente** para navegar o **Abrir PDF** para las herramientas de anotación. Navegar no cambia el número de página escrito en la nota.

## Pizarra
