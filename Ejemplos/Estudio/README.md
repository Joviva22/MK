# Ejemplo de estudio: PCP

Este recorrido prueba temas, tarjetas, materiales y resumen semanal. **Abrir estos archivos no crea categorías, tareas ni tarjetas automáticamente.** Introduce los datos desde Home cuando quieras probarlos.

Abre la carpeta **Ejemplos** como raíz de MK, no únicamente `Estudio`: así podrás ver también el PDF de demostración de `pdf/`.

## Preparación

1. En **Home → Categorías**, crea **PCP — ejemplo** (o usa tu propia asignatura).
2. Abre [pcp-concurrencia.md](pcp-concurrencia.md). En **Home → Estudio**, selecciona esa categoría y pulsa **Vincular nota abierta**.
3. En **Elegir apunte, PDF o pizarra…**, elige [seccion-critica.excalidraw](seccion-critica.excalidraw), con el filtro **Todos los archivos**.
4. Crea un tema llamado **Sección crítica** y déjalo en **Pendiente**. Selecciona el apunte y pulsa **Vincular material**; repite con la pizarra.
5. Usa [tarjetas-pcp.md](tarjetas-pcp.md) para crear dos tarjetas en **Repaso y examen**. Vuelve al tema y vincúlalas individualmente.

## Comprobar comprensión y errores

Para ver nota, PDF y dibujo al mismo tiempo, sigue [Vista dividida](vista-dividida.md). También puedes abrir la vista directamente desde el botón de tu asignatura o tema en Estudio.

1. Las tarjetas nuevas aparecen como repasos pendientes del tema.
2. Cambia el tema a **Practicando**. En **Modo examen**, escribe un intento, muestra la referencia y marca una tarjeta **Incorrecta** para probar el indicador de errores.
3. En **Practicar errores**, inténtala de nuevo y marca **Correcta** si corresponde: desaparece la señal de error del último examen. Esto no cambia la programación de repaso.
4. Cambia el tema a **Dominado** cuando lo consideres justificado. Los repasos pendientes siguen visibles; MK no cambia por ti la autoevaluación.

## Probar el resumen semanal

En Home crea una tarea **Practicar exclusión mutua** dentro de la categoría de ejemplo y márcala completada hoy. No basta con marcar una casilla en una nota: el resumen usa las tareas de Home.

En Estudio, vincula una categoría Pomodoro propia y registra una sesión (también cuenta el tiempo parcial guardado). Pulsa **Actualizar** para refrescar el resumen: debería mostrar el tiempo registrado y una tarea completada esta semana. Usa **Semana anterior** para comparar, y **Esta semana** para regresar.

El apunte [materiales-en-nota.md](materiales-en-nota.md) sirve para probar un PDF y una pizarra incrustados. El PDF es una muestra de fotosíntesis ya existente, **no un apunte de PCP**.

## Limpiar la prueba

Desvincular materiales o eliminar temas no borra archivos ni tarjetas. Si quieres limpiar también las tarjetas o tareas de ejemplo, elimínalas desde sus respectivos paneles. No borres tu asignatura real para limpiar una prueba.
