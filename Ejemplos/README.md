# Ejemplos de uso de MK

Cada archivo de esta carpeta muestra una función distinta con contenido real, listo para abrir en MK y probar. Abrí esta carpeta como raíz (**Carpeta** en la toolbar → elegí `Ejemplos/`) para que las funciones que necesitan una carpeta abierta (nota diaria, grafo, búsqueda) funcionen.

| Archivo | Qué muestra |
|---|---|
| [`diagramas-mermaid.md`](diagramas-mermaid.md) | Flowchart, secuencia y Gantt con Mermaid |
| [`ejecutar-codigo.md`](ejecutar-codigo.md) | Botón ▶ Ejecutar sobre bloques `js` |
| [`tablero-kanban.md`](tablero-kanban.md) | Columnas y tarjetas para el tablero Kanban |
| [`home-y-recordatorios.md`](home-y-recordatorios.md) | Tareas con `📅 fecha` que aparecen solas en el calendario del Home, y cómo probar los avisos |
| [`live-preview.md`](live-preview.md) | Nota completa para probar el modo Live Preview (`Ctrl+Shift+L`) |
| [`formato-avanzado.md`](formato-avanzado.md) | Callouts, resaltado, etiquetas, wikilinks, tareas, fórmulas, tablas y código |
| [`graficos.md`](graficos.md) | Base de datos **Gastos** con vistas Gráfico (torta, barras por mes), Calendario y "Sin pagar"; bloques `chart` y `database` en la nota |
| [`pdf/escribir-en-pdf.md`](pdf/escribir-en-pdf.md) | Un **formulario PDF rellenable** y un **apunte** para subrayar y escribir encima |
| [`multimedia/multimedia.md`](multimedia/multimedia.md) | Foto (SVG), audio (Opus) y video (WebM) abiertos y embebidos en una nota |
| [`ia-y-terminal.md`](ia-y-terminal.md) | F5 para correr código, terminal integrada (con pantalla dividida) y "Abrir con IA" |
| [`bases-de-datos.md`](bases-de-datos.md) | Bases de datos relacionales tipo Notion: columnas tipadas, relación entre bases, fórmula, vista tablero y la base mostrada **dentro de la nota** (bloque `database`) |
| [`Plantillas/diaria.md`](Plantillas/diaria.md) | Plantilla para la **nota diaria**: en ⚙ Ajustes → Nota diaria poné `Plantillas/diaria.md` y apretá `Ctrl+Shift+D` |
| [`tarjetas-anki.md`](tarjetas-anki.md) | Preguntas/respuestas para exportar a Anki |
| [`snippets-y-plantillas.md`](snippets-y-plantillas.md) | Cómo probar `/fecha`, `/hora` y tus propios snippets |
| `grafo-recetas.md`, `grafo-panaderia.md`, `grafo-lista-compras.md` | Tres notas enlazadas entre sí con `[[wikilinks]]`, para ver el grafo con datos reales |
| `sintaxis.py`, `sintaxis.c`, `sintaxis.cpp`, `Sintaxis.java`, `sintaxis.sh` | Resaltado de sintaxis del editor para cada lenguaje — abrí cada uno directo (son archivos de verdad, no bloques de código adentro de un `.md`) |

Para una guía especializada de cada función (cómo usarla y para qué sirve), ver la carpeta [`../Guias/`](../Guias/README.md).

Ver también `MANUAL.md` en la raíz del proyecto para la explicación completa de cada función.
