# Comandos y atajos de MK

Referencia rápida y resumida. Para la explicación completa de cada función, ver [`MANUAL.md`](./MANUAL.md).

## Archivo y pestañas

| Atajo | Acción |
|---|---|
| `Ctrl+N` | Nuevo documento |
| `Ctrl+O` | Abrir archivo |
| `Ctrl+S` | Guardar |
| `Ctrl+Shift+S` | Guardar como |
| `Ctrl+W` | Cerrar pestaña activa |
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | Pestaña siguiente / anterior |

## Buscar y navegar

| Atajo | Acción |
|---|---|
| `Ctrl+F` | Buscar/reemplazar en el archivo actual — `Enter`/`Shift+Enter` salta a la coincidencia siguiente/anterior, `Escape` cierra |
| `Ctrl+Shift+F` | Búsqueda global en la carpeta abierta (navega a otro archivo) |
| `Ctrl+Shift+P` | Paleta de comandos — todo lo que hace MK, filtrable por texto |
| `Ctrl+Shift+T` | Etiquetas (`#tag`) de la carpeta abierta |
| `Ctrl+Shift+B` | Backlinks del archivo activo (qué otras notas lo enlazan) |

## Ver / organizar

| Atajo | Acción |
|---|---|
| `Ctrl+B` | Ocultar/mostrar el sidebar de archivos |
| `Ctrl+Shift+O` | Índice del documento (encabezados) |
| `Ctrl+Shift+E` | Modo enfoque (solo editor) |
| `Ctrl+Shift+R` | Modo lectura (solo preview) |
| `F11` | Pantalla completa / escritura sin distracciones |
| `Ctrl+clic` en el sidebar | Selección múltiple de archivos (mover/eliminar en bloque) |

## Escribir

| Atajo | Acción |
|---|---|
| `Ctrl+Space` | Autocompletado (palabras ya usadas en el documento) |
| `Ctrl+scroll` / `Ctrl+=` / `Ctrl+-` / `Ctrl+0` | Achicar / agrandar / resetear el tamaño de fuente del editor |
| `Ctrl+Shift+D` | Abrir (o crear) la nota diaria de hoy |
| `/fecha`, `/hora` + espacio/Enter/Tab | Snippets de texto — fecha y hora de hoy (más los tuyos propios, desde ⚙ Ajustes) |

## General

| Atajo | Acción |
|---|---|
| `Escape` | Cerrar el panel, menú o diálogo que esté abierto |

Ver también [`README.md`](./README.md) para qué es MK y cómo correrla, y [`MANUAL.md`](./MANUAL.md) para cómo usar cada función paso a paso.
