# Primeros pasos

**Para qué sirve:** arrancar con MK en 5 minutos — abrir tu carpeta de notas, crear el primer documento y saber dónde está cada cosa.

## La pantalla

| Zona | Qué es |
|---|---|
| **Toolbar** (arriba) | Botones: Carpeta, Home, Nuevo, Abrir, Guardar, herramientas, Exportar, Ajustes, Tema |
| **Sidebar** (izquierda) | Árbol de archivos de la carpeta abierta — ver [sidebar-archivos.md](sidebar-archivos.md) |
| **Editor** (centro) | Donde escribís Markdown, con pestañas arriba |
| **Preview** (derecha) | El resultado renderizado, en vivo |
| **Barra de estado** (abajo) | Lenguaje del archivo, Pomodoro, etc. |

## Tres formas de empezar

1. **Carpeta** → elegí la carpeta donde vas a guardar tus notas. *Es la forma recomendada*: etiquetas, búsqueda, grafo, nota diaria, Kanban por carpeta y bases de datos la necesitan.
2. **Nuevo ▾** → pestaña nueva, vacía o desde plantilla (Apuntes, Documentación, Trabajo universitario, README, Fórmulas). Las plantillas completan `{{fecha}}` y te piden `{{titulo}}`.
3. **Abrir** → un archivo suelto (`.md`, `.txt`, `.tex`, `.docx`, código...).

MK recuerda la última carpeta y todas las pestañas abiertas (guardadas o no) para la próxima vez.

## Tu primera nota

1. Abrí una carpeta.
2. Clic derecho en la raíz del sidebar → **Nuevo archivo...** → `mi-primera-nota.md`.
3. Escribí:
   ```markdown
   # Hola MK
   Esto es **negrita**, esto *cursiva*, y esto una tarea:
   - [ ] Probar el preview
   ```
4. Mirá el preview a la derecha. Se guarda solo (autoguardado cada 1 s).
