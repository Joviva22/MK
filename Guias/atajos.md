# Todos los atajos

**Para qué sirve:** usar MK sin levantar las manos del teclado. Funcionan tenga el foco quien lo tenga.

## Archivos y pestañas
| Atajo | Acción |
|---|---|
| `Ctrl+N` | Nuevo documento |
| `Ctrl+O` | Abrir archivo |
| `Ctrl+S` / `Ctrl+Shift+S` | Guardar / Guardar como |
| `Ctrl+W` | Cerrar pestaña |
| `Ctrl+Q` | Salir de MK (cerrar la ventana solo la manda a la bandeja) |
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | Pestaña siguiente / anterior |

## Navegar y buscar
| Atajo | Acción |
|---|---|
| `Ctrl+P` | Abrir archivo por nombre |
| `Ctrl+Shift+P` | Paleta de comandos |
| `Ctrl+F` | Buscar / reemplazar |
| `Ctrl+Shift+F` | Búsqueda global |
| `Ctrl+Shift+T` | Etiquetas |
| `Ctrl+Shift+B` | Backlinks |
| `Ctrl+Shift+O` | Índice del documento |

## Planificar
| Atajo | Acción |
|---|---|
| `Ctrl+Shift+H` | **Home** (semana / mes) |
| `Ctrl+Shift+D` | Nota diaria de hoy (carpeta y formato en ⚙ Ajustes) |
| `Ctrl+,` | Abrir / cerrar ⚙ Ajustes |
| `Ctrl+Shift+M` | Ocultar / mostrar la barra superior (auto-ocultar) |

## Terminal
| Atajo | Acción |
|---|---|
| `` Ctrl+` `` / `Ctrl+Ñ` | Mostrar/ocultar terminal |
| `Ctrl+Shift+C` / `Ctrl+Shift+V` | Copiar / pegar en la terminal |
| `Ctrl+Shift+5` | Dividir: otra terminal al lado, en la misma pestaña |
| `F5` | Guardar y ejecutar el archivo actual en la terminal |
| `Ctrl+F` (en la terminal) | Buscar en la salida |

## Escribir
| Atajo | Acción |
|---|---|

## Sin atajo (desde `Ctrl+Shift+P`)
Bases de datos · Kanban · Grafo · Herramientas PDF · Versiones anteriores · Git control fino · Tema personalizado · Pomodoro.

## Sin mouse (teclado y lectores de pantalla)

| Dónde | Teclas |
|---|---|
| Pestañas (con el foco en una: `Tab` hasta la barra de pestañas) | `←` / `→` cambian de pestaña, `Inicio` / `Fin`, `Supr` la cierra |
| Árbol de archivos (`Tab` hasta el sidebar) | `↑` / `↓` recorren, `Enter` o `Espacio` abren, `→` despliega una carpeta, `←` la pliega o sube a la carpeta padre |
| Menús (Nuevo ▾, Exportar ▾, IA ▾) | `Enter` / `↓` abren y entran, `↑` / `↓` recorren, `Esc` cierra y vuelve al botón |
| Diálogos (Ajustes, Home, paletas…) | El foco entra solo; `Tab` no se escapa del diálogo; al cerrar vuelve a donde estabas |

Todos los botones de ícono tienen nombre para los lectores de pantalla, y los 27 temas cumplen el contraste mínimo WCAG AA (texto y texto secundario ≥ 4,5:1): lo verifica una prueba automática.
