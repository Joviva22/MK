# Guías de MK

Una guía especializada por cada función del sistema. Cada una empieza con **para qué sirve**, sigue con **cómo usarla** paso a paso y termina con usos típicos y límites.

> Nuevo en MK: empezá por [**primeros-pasos.md**](primeros-pasos.md).
> Ejemplos para probar con datos reales: carpeta [`../Ejemplos/`](../Ejemplos/README.md). Referencia completa: [`../MANUAL.md`](../MANUAL.md).
