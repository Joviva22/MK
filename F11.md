# Cambio: quitar barra de menú superior + añadir F11

## Quitar "Archivo  Editar  Ver"

Esa fila de menú (Archivo/Editar/Ver) que aparece encima de la toolbar (📂 Carpeta / 📄 Nuevo / 📄 Abrir / 💾 Guardar / 💾 Guardar como) debe eliminarse por completo.

- Es el menú nativo de aplicación de Electron (`Menu.setApplicationMenu(...)` en `main.js`) o un menú HTML propio en `index.html` — hay que localizar cuál de los dos es y quitarlo.
- Si es el menú nativo de Electron: `Menu.setApplicationMenu(null)` lo elimina del todo (en Linux esto quita la barra de arriba).
- Si es HTML propio: eliminar el elemento del DOM y su CSS asociado.
- **Importante:** revisar que ninguna función crítica dependía solo de ese menú (ej. atajos tipo `Ctrl+O` gestionados vía `accelerator` del menú nativo) — si es así, hay que registrar esos atajos por separado (con `globalShortcut` o listeners de teclado en el renderer) para no perder funcionalidad al quitar el menú.

## Añadir F11 — pantalla completa / modo concentración

- `F11` debe alternar el modo pantalla completa de la ventana (`mainWindow.setFullScreen(!mainWindow.isFullScreen())`).
- Comportamiento esperado: oculta la toolbar y deja solo editor + preview (o editor solo, según se defina), maximizando el espacio de escritura — es el "modo concentración" ya mencionado en el roadmap.
- Al pulsar `F11` de nuevo, vuelve al estado normal con toolbar y sidebar visibles (si estaban abiertos antes).
- Registrar el atajo tanto si el menú nativo desaparece (con `globalShortcut.register('F11', ...)` en `main.js`) como si se prefiere manejarlo en el renderer con un listener de `keydown`.

## Resultado esperado

- La toolbar queda como única fila visible arriba: `📂 Carpeta | 📄 Nuevo ▾ | 📄 Abrir | 💾 Guardar | 💾 Guardar como`.
- Sin la fila "Archivo Editar Ver" encima.
- `F11` entra/sale de modo pantalla completa, ocultando UI secundaria para centrarse en escribir.
